# 项目功能介绍

## 核心定位

这是一个「出门携带清单」工具。

它的重点不是做一个通用待办软件，而是帮助用户在不同出行场景下，快速确认“该带的东西有没有带”。

## 核心功能

1. 场景清单

每个场景对应一套独立清单，例如：

- 住酒店
- 出门旅游
- 出差
- 回老家

2. 物品记录

每个场景里可以记录需要携带的物品，例如：

- 护照
- 身份证
- 充电器
- 洗漱用品

3. 出门前勾选

出门前打开对应场景清单，把已经带上的物品点一下。

点完以后，该物品就会变成“已带”状态。
